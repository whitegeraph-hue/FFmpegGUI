FFmpegGUI Linux development preview, EUPL 1.2. Original source:
https://github.com/whitegeraph-hue/FFmpegGUI/tree/linux-desktop

This directory preserves notices for the unchanged shared core, Kotlin,
AndroidX/Compose, coroutines/serialization, ORT and sherpa runtimes, plus model
attribution. Model weights are imported separately, not distributed in this
package. U2-NetP is by Xuebin Qin et al., through rembg's published ONNX file.
Parakeet model attribution and CC BY 4.0 are included separately.

JRE legal notices remain with the bundled runtime under lib/runtime/legal.
The distribution-installed FFmpeg and DejaVu packages retain their own notices
under /usr/share/doc. No Android FFmpegKit binary is included.

sources.json records additional upstream licence URLs retrieved for this port.
Review is ongoing for Skiko/Skia transitive notices before external delivery.
